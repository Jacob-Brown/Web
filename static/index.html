Protection features

          
The website exposes the same hardened compiler stack used by the service.

        

        

          

            
VM virtualization

            
Functions are lowered into custom bytecode with shuffled blocks, constants, locals, and prototypes.

          

          

            
Opcode randomization

            
Seeded opcode tables, position-dependent masks, sparse dispatch IDs, and indirect dispatch.

          

          

            
V2 encryption

            
SHA-256-derived keys, opcode S-boxes, and a second stream-cipher layer.

          

          

            
Integrity checks

            
Per-record checksums, stream digests, prototype integrity, and canary guards.

          

          

            
Hardened compression

            
Measured compression pipelines with multiple transforms and strong stages.

          

          

            
Minified output

            
The emitted artifact is compacted to a single executable line after the header.

          

        

      

    


    

      

        

          
Render deployment

          
The website is a FastAPI service and can be deployed directly from GitHub.

        

        

          

            
Build command

            pip install -r website/requirements.txt
          

          

            
Start command

            uvicorn website.main:app --host 0.0.0.0 --port $PORT
